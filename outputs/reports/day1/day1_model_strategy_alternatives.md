# DAY1 모델 설계 전략 — 대안 비교와 추천안 선정

작성일: 2026-10-01

갱신: 짧은 수명 9개 사례 비교, 전체 항목 knee 집계, cycle 10 전류 패턴 정량 분석을 반영했다.

## 문서의 목적과 선정 결과

[DAY1 요구사항](../../../provided-references/day1_requirement.md)의 Feature Engineering, Regression vs Classification, Modeling Strategy에 대응한다. [질문별 EDA 답변](day1_question_answers.md)을 근거로 여러 대안을 비교하고, 후속 구현을 시작할 **설계 추천안 하나**를 선정한다. 실제 학습·성능 비교로 최종 모델을 선정한 문서는 아니다. 추가 그래프는 생성하지 않았다.

**추천안은 초기 100회 관찰에 기반한 수명 회귀다.** `cycle_life`를 타깃으로 하고 학습 시 log10 수명으로 변환한다. 입력은 log10 ΔQ 분산과 급등값을 마스킹한 초기 QD 기울기를 기본으로 한다. Ridge를 우선 후보로 선정하고, 두 batch로 학습하여 나머지 batch를 평가하는 검증을 계획한다. cycle 10 전류 패턴은 기본 입력에 일괄 추가하지 않고 특징 하나씩 보조 비교한다. 단순 기준 모델, 일반 선형 회귀, ΔQ 단일 특징, 다른 타깃 변환 및 복잡도를 제한한 Gradient Boosting과 비교할 수 있도록 설계한다.

이 선택은 현재 관찰을 토대로 한 판단이다. 로그 변환의 우수성, 보조 기울기의 추가 예측력, Ridge의 성능은 아직 확인되지 않았다. **Ridge는 먼저 평가할 추천안이며 성능이 가장 좋은 모델로 확정한 것이 아니다. 부스팅도 작은 표본에서 사용할 수 있고 정식 비교 후보에 포함한다.**

## 2. Regression vs Classification — 무엇을 예측할 것인가?

### 2.1 문제 형태의 대안

| 대안 | 타깃 정의 | 장점 | 현재 데이터의 한계 | 선택 |
|---|---|---|---|---|
| A · 수명 회귀 | 원본 `cycle_life` | 129개 유효 수명의 연속적 차이를 보존하고 예상 수명 cycle을 제시한다 | 큰 수명 오차와 batch별 분포 차이를 고려해야 한다 | **선정** |
| B · 장·단수명 이진 분류 | 단수명 <500, 장수명 >1000; 중수명 제외 | 극단 그룹 비교와 선별 문제에 적합하다 | 중수명 65개를 제외하여 64개만 남고 단수명은 모두 batch2다 | 보류 |
| C · 단·중·장수명 3분류 | <500 / 500–1000 / >1000 | 유효 항목을 유지하고 과제의 그룹 기준을 사용한다 | 경계 근처 수명 차이를 과장하며 단수명 없는 batch가 있다 | 보류 |
| D · 장수명 여부 이진 분류 | >1000이면 장수명, 나머지 비장수명 | 129개를 유지하며 선별 기준이 단순하다 | 중·단수명 차이를 잃고 경계 근처 불확실성이 남는다 | 필요 목적이 생기면 검토 |

**A를 고른 이유:** 과제의 수명은 연속값이며 ΔQ 특징과 수명의 순위·값에 상관이 확인됐다. 이는 선형 관계나 예측 가능성이 입증됐다는 뜻은 아니다. 운영상 합격/불합격 기준도 아직 제시되지 않았으므로, 임의의 경계로 정보를 줄이는 대신 수명값을 직접 예측한다. 분류를 선택한다면 중수명 처리와 실제 선별 목적을 먼저 확정해야 한다.

### 2.2 회귀 타깃 표현의 대안

| 표현 | 장점 | 한계 | 선택 |
|---|---|---|---|
| 원래 cycle 수명 | 결과와 손실을 cycle 단위로 직접 이해한다 | 제곱 오차 학습에서는 큰 절대 오차의 영향이 크다 | 비교안 |
| `log10(cycle_life)` | 양수 타깃을 다루고 수명의 상대적 차이를 반영하는 학습을 시도한다 | 역변환 예측은 원래 수명의 조건부 평균과 같지 않다. cycle MAE 개선도 보장되지 않는다 | **기본안** |
| batch 안에서 표준화한 수명 | batch 내부 차이를 강조한다 | 새로운 batch의 수명 평균·분산을 모르면 원래 cycle로 복원하기 어렵다 | 제외 |

예측 시 `10**예측값`으로 cycle 단위에 돌려놓고 성능은 원래 단위로 평가한다. 학습 목표는 로그 수명 오차이지만 선택 지표는 cycle MAE이므로, 원수명 모델과 같은 분할에서 비교한다. 평균 보정이 필요하다면 학습 데이터 안에서만 정하고, 현재 단계에서는 보정을 적용했다고 주장하지 않는다.

**예측 시점:** 100회 관찰 직후 전체 `cycle_life`를 예측한다. 남은 수명 자체가 타깃은 아니다. 100회 이전 실패 셀에 적용할 수 있는 모델도 아니며 현재 유효 수명 최소는 392다. 기존 EDA의 계산 기준과 과제 Q100−Q10을 유지한다.

## 3. Feature Engineering — 어떤 정보를 입력할 것인가?

### 3.1 특징 구성의 대안

| 대안 | 입력 | 기대하는 역할 | 한계 | 선택 |
|---|---|---|---|---|
| F1 · ΔQ 하나 | `log10(deltaQ_var)` | 가장 단순한 주요 신호 기준을 제공한다 | 곡선 변화 외 용량 추세를 반영하지 못한다 | 필수 비교안 |
| F2 · ΔQ + 초기 추세 | F1 + `QD_slope_masked` | 전압별 변화와 초기 cycle 추세가 서로 보완되는지 확인한다 | 기울기의 관계는 batch별로 달라 추가 이득이 불확실하다 | **기본안** |
| F3 · 대체 ΔQ 통계 | F2의 log 분산을 `deltaQ_min`으로 교체 | 강한 Pearson 관계를 보인 다른 요약을 비교한다 | 분산과 다른 모양을 요약하지만 정책·품질 영향은 남는다 | 제한된 비교안 |
| F4 · 폭넓은 요약 | 용량·IR·온도·충전 시간 등 요약 특징을 함께 사용 | 추가 신호와 상호작용을 탐색한다 | 작은 표본, 중복, 결측·단위 미확인과 batch 의존성 | 후순위 |
| F5 · 곡선 직접 입력 | Qdlin 또는 ΔQ의 전압 지점 전체 | 모양 정보를 더 많이 보존한다 | 약 1000차원 대비 129개 타깃, 보간 품질·차원 축소 필요 | 이번 기본안에서 제외 |
| F6 · 전류 패턴 보조 | F1 또는 F2 + cycle 10 패턴 하나 | 충전 조건의 관측 정보를 추가한다 | 정책과의 중복·batch 의존성·관측 공백 영향 | 보조 비교안 · 최대 I부터 |

**F2를 고른 이유:** 특징을 두 개로 제한하면서 전압별 용량 변화와 회차별 초기 추세가 서로 보완되는지 비교할 수 있다. 보완 분석에서도 두 신호는 동일한 의미가 아니었다. batch2 단수명 그룹에는 초기 QD 증가가 보이고, 마스킹 기울기–수명 Pearson은 batch1 +0.524, batch2 −0.484, batch3 +0.361로 방향이 다르다. 따라서 기울기가 음수일수록 항상 수명이 짧다는 규칙을 부여하지 않는다. F2는 추가 정보의 가능성을 확인하는 기본 실험안이며 F1보다 우수하다는 선택은 아니다. 내부 검증에서 기울기의 보완 효과가 없거나 특정 검증 batch의 오차를 악화시키면 F1로 축소하는 것을 후속 실험의 선택 규칙으로 둔다.

### 3.2 기본 특징의 정확한 정의

| 특징 | 계산 | 처리와 근거 |
|---|---|---|
| `log10_deltaQ_var` | 같은 전압 격자의 Q100−Q10에 대해 전체 지점 분산(ddof=0)을 계산하고 log10 변환 | 여러 자릿수의 양수 분산을 압축한다. 로그 축 패턴을 근거로 시험하는 변환이며 선형성이 검증된 것은 아니다. |
| `QD_slope_masked` | cycle 10–100의 실제 cycle 번호를 x로, 분석용 QD를 y로 한 직선 기울기 | 0 이하·비유한 QD 및 >1.32 Ah 값을 가린다. 유효 5개 이상에서 계산하며 회차를 다시 번호 매기지 않는다. |

`deltaQ_var`가 0 이하 또는 비유한 값이면 로그를 계산하지 않는다. 임의의 작은 상수를 더하지 않고 값과 원인을 기록해 해당 특징을 결측으로 둔다. 격자·회차 대응 실패와 Qdlin 범위 검토 플래그는 별도로 보존한다. 검토 플래그 자체가 원본 삭제를 뜻하지 않는다. 다만 회차 대응 실패나 잘못된 전압 격자로 ΔQ를 정의할 수 없는 항목은 측정값의 단순 결측과 구별한다. 이 경우 원자료를 확인할 때까지 해당 항목을 기본 ΔQ 모델의 학습·평가 대상에서 제외하고, 제외 항목 수와 이유를 기록한다. 중앙값으로 잘못된 곡선의 내용을 대신하지 않는다.

마스킹은 기존 QD>1.32 Ah 탐색 기준을 활용한 **설계 제안**이다. 상관이 높아져서 정답이라고 선택한 것이 아니며 원본 유지 조건도 민감도 비교에 남긴다. 낮은 양수 용량을 임의로 정상화하거나 수명 이후 값으로 초기 결측을 채우지 않는다.

### 3.3 기본 입력에서 제외할 항목과 이유

- `deltaQ_min`: 주요 대체 후보로 남기되 분산과의 강한 중복 때문에 기본안에는 함께 넣지 않는다.
- `std_QD`, `delta_QD`: 초기 추세와 중복될 수 있으므로 기본 기울기와 동시에 확대하지 않는다.
- IR·온도: IR 부재와 온도 극단값, batch별 관계 차이를 확인했다. 확장 모델에서 품질 처리와 추가 효과를 검토한다.
- 전류 패턴: 이제 정량 근거가 있어 F6 보조 후보로 둔다. 기본 입력 두 개에 일괄 추가하지 않으며 3.4절 기준으로 하나씩 비교한다.
- 요약 충전 시간·정책 문자열: 집계 의미와 조건 정리가 필요하다. 현재 두 특징 기본안에서는 제외하고, 작은 정책 표본과 미관측 정책을 고려해 확장 여부를 판단한다.
- `batch`, `cell_id`: 저장·검증 키로 사용한다. 새로운 batch로 전이하는 기본 모델의 수치 입력으로 사용하지 않는다.
- 수명 그룹, 전체 기록 길이, 수명 이후 관측 수, 전체 구간 평균·기울기, knee: 타깃 또는 관측 시점 이후 정보를 사용하므로 초기 예측 입력에서 제외한다.

### 3.4 전류 패턴의 보조 후보와 추가 조건

다음은 **cycle 10 패턴–저장 수명** 상관이다. 각 값은 Pearson / Spearman이며 수명 유효 표본은 batch1 46, batch2 39, batch3 44다. 초기 QD 기울기와의 상관과 구별한다.

| 코드 · 특징 | batch1 | batch2 | batch3 | 후보로 두는 이유와 우선순위 |
|---|---:|---:|---:|---|
| `peak_I_native` · 최대 양수 I | -0.580 / -0.495 | -0.161 / -0.328 | -0.708 / -0.585 | 세 batch에서 두 계수 모두 음수 · 첫 보조 비교 |
| `mean_positive_I_native` · 시간 가중 평균 양수 I | -0.644 / -0.638 | -0.102 / +0.014 | -0.199 / +0.025 | batch1에서 강하지만 batch2·3의 순위 관계는 약함 · 후순위 |
| `positive_duration_native` · 관측 양수 전류 시간 | +0.618 / +0.657 | +0.033 / +0.160 | +0.134 / -0.035 | batch1에서 강하지만 batch3의 순위 방향은 다름 · 후순위 |
| `near_peak_time_share` · 최대 I의 80% 이상 유지 비율 | +0.409 / +0.297 | +0.054 / +0.128 | +0.504 / +0.510 | 세 batch에서 양수지만 batch2는 약함 · 후속 대체 비교 |
| `late_minus_early_I_native` · 후반−전반 평균 I | +0.779 / +0.696 | +0.193 / +0.284 | +0.320 / +0.088 | batch1에서 강하지만 batch3의 순위 관계는 약함 · 후속 대체 비교 |

최대 I는 기존 갤러리의 `peak_positive_I_cycle10`과 같은 최대값이며 새로운 독립 신호를 발견했다는 뜻은 아니다. 이번 보완은 수명·마스킹 기울기와의 관계를 확인하고 최대값 외 관측 패턴을 추가한 것이다. 세 batch에서 방향이 같다는 이유로 ΔQ를 대체하거나 충전 전류의 인과 효과를 주장하지 않는다. ΔQ와 이미 겹치는 정보를 줄 수도 있으므로 보조 입력의 추가 효과를 검증한다.

시간 가중 지표는 I>0.05인 양수 구간에서만 계산하고, 양수 시간 간격 중앙값의 20배를 넘는 공백과 부호 전환 구간은 제외한다. ‘후반·전반’은 누적 관측 양수 시간의 절반이며 SOC 단계가 아니다. batch1 cell 18의 공백을 제외해도 전류 패턴 전체가 완전하게 복원된 것은 아니다. 후반−전반 I–수명 Pearson은 해당 셀 제외 시 +0.791(n=45)로 전체 +0.779와 같은 방향이지만 정책 영향은 남는다.

패턴 지표는 처음부터 **F1/F2에 하나만 추가**한다. 우선 최대 I를 비교하고, 필요할 때 유지 비율 또는 후반−전반 I를 대체 후보로 검토한다. 단위가 미확정이라는 사실만으로 저장 수치를 통계 입력에서 자동 배제하지는 않는다. 다만 batch 간 스케일·저장 규칙이 비교 가능한지 확인하며 A·분·C-rate 등으로 해석하거나 변환하지 않는다. 관측 양수 시간이 없으면 시간 기반 특징은 결측으로 기록한다.

수명 정의 그룹의 비율이나 평균을 셀의 입력으로 넣지 않는다. 패턴 자체는 cycle 10 정보로 계산하되, 전체 데이터의 수명 상관을 보고 선택한 후보임을 공개하고 후속 선택은 학습 내부 검증에서 한다. 기존 Q5의 ‘가장 강한 특징’은 원래 검토한 12개 특징 안의 순위이며 이번 추가 패턴 전체의 성능 순위로 확대하지 않는다.

## 4. 데이터 처리 방식의 대안과 선택

| 항목 | 대안 비교 | 선정 기준 |
|---|---|---|
| 수명 누락 | 추정 라벨로 채우기 / 학습 정답에서 제외하기 | **10개를 지도학습 정답에서 제외**하고 139개 원본 항목은 보존한다. 누락을 실패나 검열로 단정하지 않는다. |
| 특징 결측 | 완전한 행만 사용 / 학습 중앙값 대체+결측 표시 | **학습 중앙값 대체+결측 표시**. 원인과 실제 사용 수를 기록한다. 현재 기본 특징에서는 대체가 필요하지 않을 수 있다. |
| QD 급등 | 유지 / 마스킹 / 행·셀 삭제 | **분석용 값만 마스킹**하고 원본 유지 비교를 남긴다. 셀 전체를 자동 삭제하지 않는다. |
| 전류 패턴의 공백·단위 | 간격을 연결해 계산 / 공백 제외·원스케일 유지 | **기존 공백 제외 기준과 저장 스케일을 유지**하고 공백 여부·사용 구간 수를 함께 기록한다. 임의의 단위 변환은 하지 않는다. |
| 입력 스케일 | 원스케일 / 표준화 | **Ridge 입력 표준화**. 평균·표준편차는 각 학습 분할에서 계산한다. |
| batch 처리 | 독립 모델 / 혼합 모델 / batch 인코딩 | **두 batch를 합친 공통 모델로 나머지 batch 평가**. batch별 독립 모델은 항목 수가 작아 보조 대안이다. |

결측 지표는 입력 특징에 대한 초기 품질 지표만 사용한다. 전체 기록을 확인한 품질 상태가 초기 입력으로 섞이지 않도록 계산 시점을 명시한다. 학습 분할에서 한 특징이 전부 결측이면 중앙값을 계산할 수 없으므로 해당 특징 사용을 중단하고 원인을 기록한다.

결측 대체·표준화·데이터에서 정하는 변수 선택과 튜닝은 검증 데이터를 제외한 학습 분할 안에서 수행한다. 이러한 전처리와 모델을 Pipeline으로 묶는 원칙은 [scikit-learn의 데이터 누수 안내](https://scikit-learn.org/stable/common_pitfalls.html)를 따른다.

|---|---|---|---|
| 학습 수명 중앙값 상수 예측 | batch별 타깃 차이가 커 특징 없는 예측과 비교할 필요가 있다 | 입력을 반영하지 못한다 | 필수 기준 모델 |
| 일반 선형 회귀 | 기본 특징 두 개의 단순한 관계를 비교한다 | 변환 후 선형성은 미확인이다 | 필수 비교안 · 규제 필요성 확인 |

### 5.2 Ridge를 먼저 평가하는 구체적인 이유

Ridge는 다음 목적함수를 최소화하는 선형 모델이다.

```text
예측 오차의 제곱합 + alpha × 계수 제곱합
```

첫 항은 학습 데이터를 잘 설명하게 하고, 두 번째 항은 계수가 지나치게 커지는 것을 제한한다. alpha가 클수록 제약이 강해져 학습 데이터의 작은 차이에 덜 민감해질 수 있지만, 필요한 관계까지 줄여 과소적합할 수도 있다. 따라서 규제는 표본 부족을 해결하는 장치가 아니라 복잡도를 조절하는 선택이다. 이 기능은 [Ridge 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)에 근거한다.

| 데이터 관점의 근거 | 연결되는 알고리즘 특성 | 판단의 범위 |
|---|---|---|
| batch 제외 시 학습 83–90개, 기본 특징 두 개 | 적은 계수의 선형 모델에 L2 제약을 적용 | 단순하고 통제 가능한 출발점이며 성능 보장은 아님 |
| QD 기울기는 batch2 단수명에서 양수이며 수명 관계도 batch별로 다름 | 계수 크기를 제한하고 단일 특징 모델과 비교 가능 | 하나의 공통 계수로 설명되지 않을 수 있으며 규제만으로 해결되지 않음 |
| ΔQ 분산과 최솟값이 강하게 중복 | 대표 특징을 선택하고, 확장 시 규제 검토 | 기본안에 두 통계를 함께 넣지 않으므로 릿지가 필수라는 근거는 아님 |
| EDA에서 발견한 신호를 설명해야 함 | 표준화한 특징의 계수 방향을 확인 가능 | 인과 효과나 비선형 구조의 부재를 증명하지 않음 |

1. **표본 규모:** 유효 수명 항목은 129개이고 batch 제외 학습에는 83–90개가 남는다. 복잡도를 제한하는 출발점을 택했다. 이 수치가 특정 모델의 적합 여부를 결정하는 절대 임계값은 아니다.
2. **단순한 기본 입력:** 특징 두 개의 관계를 먼저 확인하면 어떤 신호가 추가 예측력을 주는지 비교하기 쉽다. 일반 선형 회귀를 함께 평가해 규제의 실질적인 이점을 확인한다.
3. **계수 안정성:** L2 규제로 계수 크기를 제한한다. 보조 기울기의 영향과 특징 확장 시 불안정성을 완화하려는 목적이다. 다만 기울기가 잘못된 관계를 보이거나 분포가 바뀌는 문제까지 해결되지는 않는다.
4. **EDA와 연결한 설명:** 표준화된 특징의 계수 방향과 조건별 변화를 비교할 수 있다. 인과 효과나 단독 중요도로 해석하지 않으며, 설명 용이성을 성능 우위의 증거로 삼지 않는다.

전체 후보에서는 ΔQ 분산과 최솟값의 중복이 강하지만 기본안은 둘을 동시에 사용하지 않는다. 따라서 **다중공선성이 심하므로 Ridge가 반드시 필요하다는 주장은 하지 않는다.** 지금의 추천은 작은 표본·적은 특징·계수 통제·설명 용이성을 함께 고려한 것이다. 일반 선형 회귀가 비슷하거나 더 좋은 검증 결과를 보이면 그 모델을 선택할 수 있다.

### 5.3 부스팅을 우선 추천안으로 고르지 않은 이유와 비교할 이유

**작은 표본만으로 부스팅을 배제하지 않는다.** 깊이·리프 크기·규제·학습률 등을 통제하면 작은 표본에서도 사용할 수 있다. 다만 현재는 다음 이유로 Ridge 이후 비교 순서를 잡았다.

- 기본 입력이 두 개이고, 변환된 입력과 타깃에서 단순 모델의 오차를 아직 확인하지 않았다. 복잡한 관계를 모델링하는 추가 이득이 있는지 먼저 비교해야 한다.
- batch는 세 개뿐이다. 깊이·트리 수·학습률·규제·샘플링을 광범위하게 탐색하면 검증 자료에 맞춰 설정을 고를 위험이 커진다.
- 용량 급등과 보간 곡선 검토 대상이 있다. 부스팅도 입력 품질을 자동으로 보장하지 않으므로 동일한 품질 기준과 분할로 비교해야 한다.

반대로 정책별 관계가 다르고, 초기 기울기와 전류 패턴이 지표·batch에 따라 수명과 다른 관계를 보이므로 **단순 선형 모델만으로 충분한지 비교할 이유가 있다.** 이 관찰에는 특이값·표본 구성·batch 차이도 영향을 줄 수 있으므로 비선형성을 입증한 것으로 해석하지 않는다. 부스팅과의 비교는 이러한 한계를 포함해 예측 오차가 개선되는지 확인하기 위한 것이다. batch 차이가 데이터에 없는 조건에서 생긴다면 부스팅도 이를 자동으로 복원하지 못한다. 부스팅의 이득과 F6 특징 추가의 이득은 각각 같은 모델 또는 같은 특징을 고정해 비교한다.

첫 부스팅 비교는 기존 scikit-learn의 `GradientBoostingRegressor`로 계획한다. 작은 표본에서는 히스토그램 기반 구현의 구간화가 분할 위치를 거칠게 만들 수 있어 일반 구현을 고려할 수 있다는 [scikit-learn 공식 안내](https://scikit-learn.org/stable/modules/ensemble.html#gradient-boosted-trees)를 참고했다. 대규모 학습 속도가 현재의 주요 선택 기준은 아니다.

XGBoost와 LightGBM도 타당한 후보다. [XGBoost 튜닝 안내](https://xgboost.readthedocs.io/en/stable/tutorials/param_tuning.html)는 트리 복잡도와 샘플링을 통한 과적합 제어를 설명하고, [LightGBM 튜닝 안내](https://lightgbm.readthedocs.io/en/stable/Parameters-Tuning.html)는 리프 수·깊이·리프 최소 데이터 수 등의 제어를 설명한다. 이들을 사용하지 않은 상태에서 성능이 나쁘다고 판단하지 않는다. 우선 한 부스팅 구현으로 비교하고 필요할 때 후보를 확대한다.

### 5.4 기본 학습 흐름

```text
100회까지 관측된 특징
→ log10 ΔQ 분산 + 급등 마스킹 QD 기울기
→ 학습 중앙값 대체·결측 표시(필요할 때)
→ 학습 기준 표준화
→ Ridge로 log10(cycle_life) 학습
→ 역변환하여 cycle 수명 예측
→ 원래 cycle 단위로 평가
```

부스팅 비교에서도 동일 항목·특징 정의·타깃·평가 분할을 유지한다. 트리 입력에 표준화를 필수로 요구하지 않으며, 모델에 맞는 전처리를 학습 분할 안에서 수행한다. 특징 수와 모델 종류를 동시에 바꿔서 생긴 차이를 모델 자체의 성능 차이로 설명하지 않는다.

## 6. 검증 방식의 대안과 선택

### 6.1 분할 기준

| 대안 | 답하는 질문 | 한계 | 선택 |
|---|---|---|---|
| 전체 항목 무작위 분할 | 이미 본 batch와 비슷한 항목에 잘 맞는가? | 서로 다른 batch의 정보가 양쪽에 섞이고 반복 셀이 있으면 누수 가능 | 보조 평가 |
| batch 하나씩 제외 | 다른 batch에서 학습한 관계가 평가 batch에도 유지되는가? | batch가 3개뿐이며 학습에 없는 수명 범위로의 전이가 어렵다 | **주 평가** |
| 정책별 그룹 분할 | 보지 못한 정책에 적용되는가? | 정책별 표본이 작고 정책 정의의 정리가 필요하다 | 후속 별도 목적 |
| 동일 물리 셀별 그룹 분할 | 같은 배터리의 반복 측정이 양쪽에 들어가지 않는가? | 실제 대응표가 필요하다 | 모든 분할에 우선 적용할 원칙 |

**검증 목적은 관측하지 않은 batch로의 전이 가능성을 점검하는 것으로 선택했다.** 과제는 batch 간 비교를 요구하지만 특정 학습·평가 분할을 지정하지는 않는다. 같은 batch 안의 새 셀 예측이 실제 활용 목적이라면 물리 셀 그룹을 유지한 batch별 분할을 별도로 설계해야 한다.

특히 batch3의 최대 수명은 1935지만 batch1·2의 최대는 1227·1186이다. batch3를 제외하면 학습에서 없는 장수명 범위를 평가하게 된다. 이 경우의 실패는 모델 복잡도뿐 아니라 학습 범위 부족과 분포 차이로 해석해야 한다. 선형 모델도 범위 밖 예측이 정확하다고 보장되지 않는다.

주 평가는 다음 3회로 계획한다. 아래 수는 현재의 파일 항목 기준이며 독립 물리 셀 수로 확정된 숫자가 아니다.

| 평가 batch | 학습 batch | 학습 항목 수 | 평가 항목 수 |
|---|---|---:|---:|
| batch1 | batch2 + batch3 | 83 | 46 |
| batch2 | batch1 + batch3 | 90 | 39 |
| batch3 | batch1 + batch2 | 85 | 44 |

batch를 그룹으로 하나씩 제외하는 구현에는 [LeaveOneGroupOut](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.LeaveOneGroupOut.html)을 사용할 수 있다. 이 분할만으로 같은 물리 셀의 batch 간 반복 측정을 막는 것은 아니다.

**학습 전 필요한 확인:** 동일 물리 셀의 측정 연장·중복 여부와 batch별 수명 정의를 확인한다. 반복 셀이 발견되면 평가 batch와 연결된 물리 셀을 학습에서 제외하거나 목적에 맞게 기록을 통합하고 위 표본 수를 다시 산정한다. 데이터 누수 방지를 위해 임의의 cell_id 일치만으로 동일 셀이라고 판정하지 않는다. 수명 정의가 다른 경우에는 그대로 합친 성능을 해석하지 않는다.

현재 세 batch 모두를 EDA에서 이미 관찰했다. 따라서 후속 batch 제외 평가도 **개발 단계의 일반화 점검**이며, 완전히 보지 않은 독립 최종 시험이라고 부르지 않는다.

### 6.2 튜닝과 지표

Ridge의 alpha는 예를 들어 `0.1, 1, 10, 100`의 작은 후보 집합에서 시작한다. 최적값을 이미 정한 것은 아니다. 각 외부 학습 세트의 두 batch를 내부 검증에서 하나씩 제외하여 선택하고, 평가 batch는 튜닝에 사용하지 않는다. 물리 셀 대응을 확인한 뒤 중복 제거 원칙을 내부 분할에도 적용한다. 내부 batch가 두 개뿐이라는 한계를 기록한다.

부스팅의 첫 비교 설정은 예를 들어 `max_depth=1 또는 2`, `min_samples_leaf=10`, `learning_rate=0.05`, `n_estimators=50 또는 100`의 네 조합으로 제한한다. 이는 성능이 검증된 설정이 아니라 큰 탐색을 피하기 위한 시작안이다. 내부 검증 결과에 따라 선택하며, early stopping을 사용한다면 평가 batch를 중단 판단에 사용하지 않고 학습 측 내부 검증에서만 결정한다.

**주 지표는 MAE(cycle)**다. 실제 수명과 예측의 평균 절대 차이를 제시한다. 튜닝·모델 선택에서는 내부 검증 batch별 MAE의 단순 평균을 사용해 한 batch가 항목 수로 결과를 지배하지 않도록 한다. 외부 평가 세 batch의 MAE 단순 평균은 전체 전략의 개발 평가 요약으로 기록하며, 그 점수로 설정을 다시 고르지 않는다. 전체 항목을 합친 MAE, 큰 오차에 민감한 RMSE, 상대 오차 MAPE, batch별 R²도 보조로 기록한다. 수명값은 양수이지만 MAPE가 짧은 수명의 오차를 상대적으로 크게 반영한다는 점을 함께 설명한다.

R²가 음수여도 숨기지 않는다. 평가 batch의 타깃 범위가 좁으면 R²와 절대 오차가 서로 다른 인상을 줄 수 있다. 세 평가 batch의 결과를 각각 제시하고 하나의 합산 점수로만 결론 내리지 않는다.

## 7. 제한된 비교로 추천안을 점검하는 순서

| 순서 | 비교 | 확인할 질문 |
|---|---|---|
| 1 | 중앙값 기준 모델 vs 일반 선형 회귀 vs F1·F2 Ridge | 주요 신호·기울기·규제가 각각 추가 이득을 주는가? |
| 2 | 로그 수명 vs 원수명 | 원래 cycle MAE에서도 로그 타깃이 유리한가? |
| 3 | log 분산 vs ΔQ 최솟값 대체 | 강한 두 특징 중 어떤 대표가 더 안정적인가? |
| 4 | 급등 유지 vs 마스킹 | 처리 기준에 따라 성능·계수·개별 오차가 얼마나 바뀌는가? |
| 5 | 선정 선형안 vs 제한한 Gradient Boosting | 같은 특징과 분할에서 비선형 모델이 오차를 줄이는가? |
| 6 | F1/F2 vs 최대 I 하나를 추가한 F6 | 같은 모델에서 전류가 ΔQ·기울기 밖의 추가 정보를 주는가? |
| 7 · 필요 시 | 최대 I를 유지 비율 또는 후반−전반 I로 교체 | 강한 특정 batch 상관보다 안정적인 추가 정보가 있는가? |
| 8 · 필요 시 | Random Forest, 또는 XGBoost/LightGBM 중 하나 | 다른 앙상블 구현의 추가 이득이 있는가? |

이 비교는 한꺼번에 큰 조합 탐색으로 확대하지 않는다. 조건을 사전에 기록하고 특징·타깃·모델의 선택은 학습 내부 검증에서 수행한다. 외부 평가 batch의 결과를 보고 반복적으로 추천안을 바꾸면 외부 평가 역시 모델 선택에 사용된 결과가 되므로 독립 검증이라고 주장하지 않는다.

최종 기본안을 유지하려면 중앙값 기준 대비 개선과 batch별 실패 양상을 확인해야 한다. 내부 검증에서 F2가 F1보다 도움이 되지 않으면 기울기를 제거하고, 로그 타깃이 원수명 대비 도움이 되지 않으면 원수명을 사용한다. 부스팅이 내부 검증의 평균 cycle MAE를 줄이고 특정 batch에만 개선이 집중되지 않는다면 Ridge를 대체할 후보로 선택할 수 있다. 정확한 순위뿐 아니라 batch별 오차·설정 변경에 따른 안정성·복잡도를 함께 기록한다. F6는 같은 모델·타깃·분할에서 특징을 하나 추가한 내부 검증 결과가 도움을 줄 때 채택한다. 공백 셀 제외 민감도와 정책별 표본 구성을 확인하며, 전체 데이터의 높은 상관만으로 기본안에 편입하지 않는다. 작은 차이는 성능 우위로 단정하지 않고 더 단순한 안을 우선한다. ‘의미 있는 개선’의 cycle 기준은 활용 목적의 허용 오차가 정해질 때 사전에 정하며 현재 임의의 기준을 성능 결론으로 제시하지 않는다. 이러한 조건은 후속 실험 규칙이며 현재 실제 성능에 대한 판정은 아니다.

## 8. DAY1 제출에 사용할 설계 결론

EDA에서 세 batch의 수명 분포가 다르고, 초기 ΔQ 분산·최솟값이 수명과 일관된 방향으로 연결되는 것을 확인했다. 반면 초기 QD 기울기는 급등 처리에 민감하고 단수명에서도 초기 용량 증가가 관찰됐다. cycle 10 전류 패턴은 최대 I의 수명 상관이 세 batch에서 음수지만, 평균·유지 비율·전후 변화의 관계는 batch별로 다르다. 온도·IR과 기록 공백에도 품질 검토가 필요하다. 이에 연속적인 수명 정보를 유지하는 회귀를 선택하고 원본 `cycle_life`를 타깃으로 정의한다.

기본 입력은 cycle 10–100의 log10 ΔQ 분산과 급등 마스킹 QD 기울기로 제한하며, 강하게 중복되는 ΔQ 최솟값은 대체안으로 비교한다. 로그 수명 Ridge를 먼저 평가할 설계안으로 선정한다. 단일 특징·원수명·일반 선형 회귀를 비교하고, 복잡도를 제한한 Gradient Boosting을 우선 비선형 후보로 둔다. 최대 I부터 전류 패턴 하나를 추가하는 F6를 보조안으로 비교하며, 기본 입력을 동시에 여러 특징으로 확대하지 않는다. Random Forest와 XGBoost/LightGBM은 필요에 따라 후보를 확대할 때 검토한다. 작은 표본만으로 부스팅을 배제하거나 Ridge의 성능 우위를 주장하지 않는다. batch 하나씩 제외하는 검증으로 분포 전이의 한계를 확인하고, 초기 관측 이후 정보와 동일 물리 셀의 반복 측정이 학습·평가에 섞이지 않도록 한다.

이 문서는 **EDA 기반 설계안의 선정**까지 완료한 것이다. 최고 성능 모델, 검증된 예측 정확도 또는 최적 충전 정책을 주장하지 않는다.

설계안의 선정 이유를 제출용으로 압축하면 다음과 같다.

> 학습에 사용할 수명 항목이 129개이고 batch별 분포가 다르므로, 초기 특징 두 개와 계수 크기를 제한하는 Ridge를 먼저 평가할 모델로 선정했다. ΔQ의 일관된 상관을 주요 근거로 삼되 선형성과 예측 성능은 검증 전 가정으로 남긴다. 일반 선형 회귀와 복잡도를 제한한 Gradient Boosting을 같은 특징·분할에서 비교한다. 전류 패턴은 batch별로 관계가 달라 최대 I부터 하나씩 보조 후보로 평가하며, 학습 내부 검증에서 오차·안정성·복잡도를 고려해 대안을 선택한다.

### 현재 추천안과 보조안의 구분

| 항목 | 이번 문서에서 선정한 기본안 | 후속 비교에서 변경 가능한 대안 |
|---|---|---|
| 문제·타깃 | 수명 회귀, 원본 cycle_life · 로그 학습 | 원수명 학습 |
| 핵심 입력 | log10 ΔQ 분산 + 마스킹 초기 QD 기울기 | ΔQ 단일 특징, ΔQ 최솟값 대체 |
| 전류 패턴 | 기본 입력에 일괄 포함하지 않음 | 최대 I부터 한 개씩 추가하는 F6 |
| 모델 | Ridge를 먼저 평가 | 일반 선형 회귀, 제한한 Gradient Boosting |
| 검증 | 물리 셀 대응 확인 후 batch 제외 개발 평가 | 활용 목적이 정해지면 동일 batch·정책 전이 평가 |
| knee | 사후 열화 설명에 사용 | 초기 예측 입력으로 사용하지 않음 |

보완 EDA는 기본안의 성능을 검증한 결과가 아니다. 기본안을 유지하면서도 QD 기울기의 제거 조건과 전류 패턴의 추가 조건을 더 명확하게 정하는 근거로 사용했다.
