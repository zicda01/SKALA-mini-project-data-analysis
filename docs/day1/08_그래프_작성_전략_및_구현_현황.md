# 그래프 작성 전략과 구현·관찰 현황

기준일: 2026-10-01

노트북에서 그래프를 확인하고 관찰을 쌓기 위한 작업 목록이다. 기존 그래프 **12개 전략**과 추가 그래프 **8개 전략**을 정리했다. 기존 수명 히스토그램과 갤러리 수명 분포처럼 일부 전략은 같은 질문을 서로 다른 수준에서 다룬다. 전략 수는 저장된 이미지 파일 수와 다르다.

**구현 완료**는 코드와 실행 산출물이 있는 경우다. **미구현**은 아래에 설계만 정리한 상태이며, 관찰 결과를 추정해서 채우지 않았다. 추가 전략 N01–N08의 구현·실행과 이미지 확인을 완료했다. 남은 검토는 발견한 특이값의 원본 확인과 분석 기준 결정이다.

## 2. 추가 그래프 전략

우선순위 A는 현재 해석에 영향을 주는 데이터 상태 확인, B는 기존 관계를 더 구체적으로 살펴보기, C는 열화 구조 탐색이다. 우선순위는 실행 순서의 제안이며 구현 완료를 뜻하지 않는다.

### N01 · 용량 급등값 처리에 따른 특징 변화 — 우선순위 A

- **목적 / 연결:** E02·E06의 급등값이 E11의 상관관계에 얼마나 영향을 주는지 확인한다.
- **작성 방법:** 양수 급등값 유지와 QD>1.32 Ah 마스킹 조건을 나란히 비교한다. 같은 셀의 초기 `std_QD`, `QD_slope`를 전후 연결점으로 표시하고, 각 조건의 수명 상관을 별도 패널에 표시한다. 같은 유효 셀 집합에서의 비교와 전체 유효 표본 비교를 구별한다.
- **데이터:** summary, 기존 품질 플래그, cycle 10–100. QD 요약 특징을 다시 계산한다. 상세 Qdlin을 수정하지 않으므로 ΔQ 특징은 이 처리로 바뀌지 않는다.
- **구현 여부:** 완료. `src/quality_eda.py`, `notebooks/03_quality_sensitivity.ipynb`; 세 batch 실행 및 PNG 확인 완료.
- **관찰 결과:** batch1 기울기의 수명 Pearson이 0.109→0.524로 바뀐다. batch2의 초기 특징이 바뀌는 8개 셀은 모두 수명 누락이므로 수명 상관은 같다. batch3는 변화가 없다.

### N02 · 온도 극단값과 상관계수의 민감도 — 우선순위 A

- **목적 / 연결:** E12의 batch2 온도 상관이 특정 셀에 의해 달라지는지 눈으로 확인한다.
- **작성 방법:** 셀별 초기 평균 Tmax–Tmin 산점도를 전체 범위와 정상 범위 확대 패널로 표시한다. cell 38에 ID를 붙이고, 전체 및 해당 셀 제외 조건의 n·상관계수를 함께 쓴다. 다른 batch도 같은 방식으로 확인한다.
- **데이터:** 기존 셀별 특징 CSV. 원인 확인은 cell 38의 원본 온도 시계열로 확장한다.
- **구현 여부:** 완료. 전체·확대 산점도와 검토 대상 제외 조건을 세 batch에서 실행·저장했다.
- **관찰 결과:** batch2 cell 38이 다른 셀 무리에서 크게 떨어져 있다. 평균 Tmax=400, Tmin=−270이며 포함 시 r=−0.999(n=47), 제외 시 r=+0.550(n=46)이다. batch1·3은 검토 대상이 없다. 제외는 민감도 비교이며 원본 삭제 기준이 아니다.

### N03 · 결측·특이값의 셀별 위치 지도 — 우선순위 A

- **목적 / 연결:** E05·E11에서 빠진 셀이 특정 정책이나 구간에 몰려 있는지 확인한다.
- **작성 방법:** 셀 × 품질 항목 행렬에 수명 누락, 유효 IR 없음, 초기 QD 급등, 온도 검토 상태를 표시한다. 옆에는 셀별 유효 초기 회차 수나 비율을 붙인다. 정책 이름별로 정렬하되 cell_id를 유지한다.
- **데이터:** 셀 메타데이터, summary 품질 플래그, 특징별 n. 온도 플래그는 저장 규칙 확인 후 기준을 문서화한다.
- **구현 여부:** 완료. 정책순 셀별 플래그와 초기 91회 기준 QD·IR 유효 관측 지도를 저장했다.
- **관찰 결과:** batch2 수명 누락 8개와 급등 셀 8개가 일치하며 VarCharge·SLOWCYCLE 항목에 해당한다. 셀 40–46은 IR이 없고 여러 정책에 걸쳐 있다. batch3 수명 누락 23·32는 같은 4.8C(80%)-4.8C-newstructure 정책이다.

### N04 · 충전 시간·전류 무리와 정책 연결 — 우선순위 B

- **목적 / 연결:** E10의 분리된 무리가 어떤 정책에 해당하는지 확인한다.
- **작성 방법:** 평균 chargetime–최대 양수 I 산점도를 정책별 색·기호로 표시한다. 별도 패널에는 정책별 chargetime 분포와 개별 점을 둔다. batch별 패널을 유지하고 범례가 길면 정책별 소형 패널로 나눈다.
- **데이터:** 셀 메타데이터와 기존 특징 CSV. 수명 누락 셀도 포함한다.
- **구현 여부:** 완료. `src/policy_eda.py`, `notebooks/04_policy_exploration.ipynb`; 정책 연결 PNG 저장·확인 완료.

### N05 · 상세 전류·전압의 한 cycle 패턴 — 우선순위 B

- **목적 / 연결:** 최대 전류 하나로 축약한 E10에 더해 실제 충·방전 절차의 형태를 확인한다.
- **작성 방법:** 선택 셀의 cycle 10에서 저장 시간 축에 I, V, Qc·Qd를 세로 패널로 정렬한다. 다른 정책 또는 급등 셀의 인접 cycle을 비교한다. 전류 전환 구간은 표시하되 단위와 부호 규칙을 먼저 확인한다.
- **데이터:** 상세 `cycles` 중 시간·전류·전압·용량 필드만 선택 로드. summary cycle과 상세 저장 위치의 대응을 점검한다.
- **구현 여부:** 완료. cycle 10의 정책 비교 9건과 특이 회차 전후 6건을 선택 로드해 QD·QC 대응 및 시간 순서를 확인했다. PNG 5개 저장·확인 완료.

### N06 · 그룹 내부의 ΔQ–수명 관계 — 우선순위 B

- **목적 / 연결:** E08의 관계가 수명 그룹 또는 정책 무리 안에서도 보이는지 확인한다.
- **작성 방법:** log10(ΔQ 분산)–수명 산점도를 정책별 작은 패널로 표시하고 개별 ID·n을 붙인다. 그룹 내부 상관도 보조 표로 기록하되 작은 표본이나 상수값은 계수를 생략한다. 전체 scatter를 비교 패널로 유지한다.
- **데이터:** 기존 ΔQ 특징과 정책 메타데이터를 batch+cell_id로 결합한다.
- **구현 여부:** 완료. 정책별 공통 축 패널, 유효 n 및 n≥5 상관을 세 batch에서 저장했다. 수명 그룹 내부 수치는 보조 CSV에 기록했다.
- **관찰 결과:** batch1은 정책별 n=1–3으로 계수를 생략했다. batch2·3은 정책마다 강한 음의 관계 또는 거의 없는 관계가 섞인다. batch3 5.3C(54%) 정책의 Pearson(log)은 −0.797, 5.6C(36%) 정책은 −0.040이다. 수명 그룹은 타깃 범위가 제한된 탐색이다.

### N07 · 초기 관찰 구간에 따른 특징의 변화 — 우선순위 B

- **목적 / 연결:** cycle 10–100이라는 선택에 E07·E11의 결과가 얼마나 의존하는지 확인한다.
- **작성 방법:** ΔQ를 Q50−Q10, Q75−Q10, Q100−Q10으로 계산하여 분산–수명 산점도를 나란히 표시한다. 초기 QD 기울기는 10–50, 10–75, 10–100으로 비교한다. 각 조건의 n과 Pearson·Spearman을 표로 덧붙인다.
- **데이터:** summary 및 상세 cycle 10·50·75·100. 상세 cycle의 내용 대응과 전압 격자 일치를 매번 검증한다.
- **구현 여부:** 완료. `src/window_knee_eda.py`, `notebooks/05_window_knee_exploration.ipynb`; 종료 구간 3개와 상세 대응 556건을 확인하고 N07 PNG 5개를 저장했다.
- **관찰 결과:** cycle 50에서도 ΔQ 분산과 수명의 음의 순위 관계가 보인다. batch1·3은 75·100에서 더 강하다. batch2 cell 33 cycle 75의 Qdlin 범위가 −84.27–306.74 Ah여서 Pearson 방향을 바꾼다. 원본 유지와 해당 곡선 제외 민감도를 함께 기록했다. 높은 상관만으로 예측 성능을 주장하지 않는다.

### N08 · 열화 속도 변화와 knee 후보 — 우선순위 C

- **목적 / 연결:** E03·E06에서 보이는 후반 급감의 시작점을 수치로 탐색한다. 과제 Q2의 knee point 항목은 현재 곡선 관찰까지만 진행했다.
- **작성 방법:** 먼저 선택 셀에 원래 QD와 이동 구간 기울기를 나란히 표시한다. 그다음 최소 구간 길이를 정한 분할 직선 등 명시적인 방법으로 knee 후보를 표시한다. 평활·구간 길이에 따라 후보 위치가 바뀌는지도 비교한다.
- **데이터:** 전체 summary. 결측 구간을 임의로 이어 붙이지 않고 양수 급등 처리 조건을 표시한다. 저장 수명 이후 구간을 사용할지 목적에 따라 명시한다.
- **구현 여부:** 완료. 선택 셀 10개에 연속 분할 직선과 국소 기울기를 적용했다. 급등 유지/마스킹 × 평활 3조건 × 최소 구간 2조건의 120개 결과, batch별 PNG 3개와 민감도 PNG 1개를 저장했다.
- **관찰 결과:** 기본 조건에서 10개 중 8개가 명시한 탐색 기준을 통과했다. batch1 cell 0은 미확인, batch2 cell 38은 기록 부족이다. batch1 cell 2처럼 완만한 변화도 후보가 되므로 실제 열화 전환점으로 확정하지 않았다. 결측을 잇지 않고 알려진 수명 이후 기록은 이 사후 탐색에서 제외했다.

## 4. 그래프 작성·관찰 기록 기준

- 같은 비교의 축 범위와 색 의미를 맞추고, 확대 그림을 쓰면 전체 범위도 함께 제공한다. 로그 축 여부와 축 밖 값도 표시한다.
- 모든 그래프에 batch, 구간, 사용 셀 수, 결측 처리 및 특이값 처리 조건을 기록한다. 원본과 분석용 데이터를 구별한다.
- 개별 셀을 먼저 보여주고 평균·중앙값을 함께 쓴다. 평균 막대만으로 표본 수와 셀 간 차이를 감추지 않는다.
- 그룹이 비어 있거나 표본이 작으면 그대로 표시한다. 수명 누락을 단기 수명이나 0으로 치환하지 않는다.
- 새로운 관찰에는 **보이는 패턴 → 확인한 수치 → 아직 확인하지 못한 원인**을 짧게 적는다. 예상과 실제 관찰을 구별한다.
- PNG는 `outputs/figures/`, 설명은 Markdown에 저장한다. Markdown 파일 안의 이미지 링크는 문서 위치 기준 상대 경로를 사용한다.
- 구현 완료는 코드 작성만으로 표시하지 않는다. 노트북 실행, 산출물 저장, 이미지 확인까지 마친 뒤 완료로 갱신한다.

각 추가 전략을 실행한 뒤에는 다음 형식으로 기록한다.

```text
구현 상태: 완료 / 미구현 / 코드 작성 후 실행 대기
실행 조건: batch, 셀, cycle 구간, 전처리 조건
산출물: 노트북 및 PNG 경로
관찰: 실제 확인한 패턴과 수치
추가 확인: 남은 질문과 비교 조건
```
