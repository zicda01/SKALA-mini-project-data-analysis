# 배터리 셀 하나의 데이터 구조

셀 하나에는 **그 배터리의 기본 정보와 여러 회차의 실험 기록**이 들어 있습니다. 셀 하나를 열면 무엇이 들어 있는지 필드 이름까지 붙여보면 다음과 같습니다.

```text
Batch 파일 하나
└── 배터리 셀 하나
    │
    ├── ① 기본 정보: 어떤 배터리 실험인가?
    │   ├── cycle_life       수명 값
    │   ├── policy           원본 충전 정책
    │   ├── policy_readable  읽기 쉬운 충전 정책 문자열
    │   ├── barcode          배터리 식별 관련 원본 정보
    │   └── channel_id       시험 장비 채널 관련 원본 정보
    │
    ├── ② summary: 각 회차의 결과를 요약
    │   ├── cycle            회차 번호 배열
    │   ├── QDischarge       회차별 방전 용량 배열
    │   ├── QCharge          회차별 충전 전하량 배열
    │   ├── IR               회차별 내부 저항 배열
    │   ├── Tavg             회차별 평균 온도 배열
    │   ├── Tmax             회차별 최대 온도 배열
    │   ├── Tmin             회차별 최소 온도 배열
    │   └── chargetime       회차별 충전 시간 지표 배열
    │
    ├── ③ cycles: 각 회차 내부의 상세 기록
    │   ├── 첫 번째 저장 회차
    │   │   ├── t            측정 시간 배열
    │   │   ├── I            전류 배열
    │   │   ├── V            전압 배열
    │   │   ├── T            온도 배열
    │   │   ├── Qc           누적 충전 전하량 배열
    │   │   ├── Qd           누적 방전 전하량 배열
    │   │   ├── Qdlin        전압 위치에 맞춘 방전 용량 배열
    │   │   ├── Tdlin        보간된 방전 온도 배열
    │   │   └── discharge_dQdV
    │   │                    전압에 대한 방전 용량 변화율 배열
    │   ├── 두 번째 저장 회차
    │   │   └── 위와 같은 필드 구성
    │   └── …
    │
    └── ④ Vdlin: 보간 곡선에 사용하는 전압 위치 배열
```

## summary: 필드별 배열을 회차별 표로 펼치기

`summary`는 실제로 **필드마다 배열이 저장된 구조**입니다. 같은 위치의 값을 모으면 익숙한 표의 한 행이 됩니다.

```text
cycle       = [1,    2,    3,    …]
QDischarge  = [값1, 값2, 값3, …]
Tavg        = [값1, 값2, 값3, …]
                  ↓
          같은 위치끼리 묶기
```

| cycle | QDischarge | Tavg |
|---:|---|---|
| 1 | 첫 회차의 방전 용량 | 첫 회차의 평균 온도 |
| 2 | 둘째 회차의 방전 용량 | 둘째 회차의 평균 온도 |
| 3 | 셋째 회차의 방전 용량 | 셋째 회차의 평균 온도 |

위 회차 번호는 개념 예시입니다. 실제 분석에서는 원본 `summary.cycle` 값을 유지하며 행 번호로 다시 만들지 않습니다.

## cycles: 한 회차 내부에도 여러 측정값이 있음

`cycles`에서 **회차 하나**를 꺼내면, 그 안에 다시 여러 값이 있습니다.

```text
한 회차 내부의 상세 측정 — 개념 예시

측정 시간 t   = [시점1, 시점2, 시점3, …]
전압 V        = [전압1, 전압2, 전압3, …]
전류 I        = [전류1, 전류2, 전류3, …]
온도 T        = [온도1, 온도2, 온도3, …]
```

**`summary.QDischarge`는 한 회차의 방전 용량을 숫자 하나로 보여주고, `cycles.Qd`는 그 회차 안에서 방전 전하량이 쌓이는 과정을 여러 숫자로 보여줍니다.**

상세 데이터의 저장 위치와 실험 cycle 번호의 대응은 확인이 필요합니다. 예를 들어 `CYCLE_INDEX=1`은 두 번째 저장 위치를 뜻하며, 검증 없이 실험 2회차라고 확정하지 않습니다.

## Qdlin과 Vdlin: 전압 위치를 기준으로 짝짓기

`Qdlin`은 시간 기준 배열과 구분해야 합니다. `Vdlin`의 전압 위치에 맞춘 값이므로, 두 배열의 같은 위치를 짝지어 읽습니다.

```text
Vdlin의 특정 위치  → 비교할 전압
Qdlin의 같은 위치  → 그 전압에서의 방전 용량
```

서로 다른 회차의 곡선을 같은 전압 위치에서 비교할 때 이 배열을 사용합니다. 예를 들어 ΔQ(V)는 같은 전압에서 100회차와 10회차의 방전 용량 차이를 구하는 분석입니다.

## 논리적 구조와 실제 저장 방식

위 도식은 **내용을 이해하기 위한 논리적 구조**입니다. 원본 HDF5에서는 자료들이 객체 참조로 연결되어 있습니다. 로더는 참조를 따라가며 필요한 배열을 꺼냅니다. 각 셀의 `cycles`에서도 필드별 객체 참조 배열을 따라가 특정 저장 회차의 데이터를 읽습니다.

따라서 배터리 셀 하나는 표의 한 행으로 끝나는 자료가 아니라, **기본 정보와 회차별 요약 배열, 회차 내부의 상세 배열을 품은 묶음**입니다. 계층적 저장은 데이터를 요약하거나 압축했다는 뜻과는 구분합니다.
