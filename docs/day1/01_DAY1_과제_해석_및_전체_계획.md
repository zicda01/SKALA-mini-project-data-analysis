# DAY 1 과제 해석 및 전체 계획

## 0. 현재 작업 목표

우선 노트북에서 데이터를 직접 확인하고 반복 탐색할 수 있는 분석 아키텍처를 만든다. 공통 모듈을 호출해 그래프와 표를 살펴보고, 관찰 → 가설 → 추가 분석을 반복한다. 아래 최종 과제 범위는 이 탐색 결과를 축적한 후 완성한다.

진행을 세 단계로 나눈다.

1. 기반 구축: 로딩·전처리와 재현 가능한 첫 탐색 노트북.
2. EDA: 다섯 질문을 탐색하고, 조건 변경과 Batch 비교로 해석을 검증.
3. 정리: 축적된 근거로 Feature·모델 전략을 선택하고 보고서 작성.

## 1. DAY 1 과제의 최종 목표

오늘의 목표는 단순히 Batch 1을 탐색하는 것이 아니라 다음 작업을 완료하는 것이다.

1. Batch 1, Batch 2, Batch 3 각각에 대해 동일한 EDA 수행
2. Batch 간 데이터 특성 비교
3. 5개 핵심 질문에 대한 분석 결과 정리
4. EDA에서 확인한 내용을 바탕으로 Feature Engineering 방향 수립
5. Regression 또는 Classification 중 하나의 문제 형태 선택
6. Target Variable 정의
7. 데이터 처리 및 후보 모델을 포함한 모델링 전략 제시

오늘은 **모델 학습과 성능 평가 자체를 수행하는 단계가 아니라, 모델 설계 전략을 수립하는 단계**로 본다.

## 2. 과제에서 요구하는 5개 질문

### Question 1. Cycle Life 분포는 어떻게 생겼는가?

확인 항목:

- 150 ~ 2,300 사이클 범위 Histogram
- 장수명 셀: `cycle_life > 1000`
- 단수명 셀: `cycle_life < 500`
- 이상치 셀 식별
- 특정 셀이 유독 짧은 수명을 가지는지 탐색

### Question 2. 방전 용량은 어떻게 감소하는가?

확인 항목:

- cycle별 Qd 추이
- 열화 속도가 일정한지 여부
- 열화 속도가 가속되는지 여부
- Knee Point 탐색

### Question 3. ΔQ(V) 곡선은 초기 사이클에서 차이가 보이는가?

과제에서 제시된 계산 기준:

```text
ΔQ(V) = Q(V, cycle 100) - Q(V, cycle 10)
```

확인 항목:

- 장수명 셀과 단수명 셀의 ΔQ(V) 형태 비교
- 두 그룹을 구분할 수 있는 통계값 추출
- 모델 Feature로 사용할 수 있는지 판단

### Question 4. 충전 조건(C-rate)과 수명의 관계는?

확인 항목:

- 충전 프로토콜별 평균 수명
- 고속 충전 셀의 수명이 실제로 더 짧은지
- 충전 전류 패턴과 열화 속도의 관계

### Question 5. 어떤 신호가 수명과 연관되어 있는가?

확인 항목:

- 초기 사이클 Feature와 Cycle Life 간 상관계수
- 가장 강한 관계 식별
- Feature 간 Multicollinearity 확인

## 4. Batch 1의 역할

Batch 1은 먼저 분석 코드를 개발하고 검증하는 기준 데이터로 사용한다.

```text
Batch 1
→ 코드 개발 / 디버깅
→ 분석 로직 확인
```

단, 최종 DAY 1 산출물은 Batch 1만으로 끝내지 않는다.

동일한 분석 코드를 Batch 2, Batch 3에 적용하여 각 Batch의 특성을 비교해야 한다.
