# 전처리 기준과 첫 열화 곡선 탐색

2026-10-01 실행 결과를 기록한다. 최종 모델 전략 보고서가 아니라 노트북 탐색의 근거와 다음 질문을 정리한 작업 기록이다.

## 구현과 실행

- `src/preprocess.py`: 원본을 보존한 품질 플래그, 변수별 분석용 값, 셀 진단, 대표 셀 선택.
- `src/eda.py`: 전체/초기 구간, 원본/분석용 QD 비교, 수명 그룹별 대표 셀 그래프.
- `notebooks/01_batch_eda.ipynb`: 조건 변경, 특이값 위치·주변 회차, 수명 기준 도달, 그래프와 세 Batch 공통 점검.
- `tests/test_preprocess.py`: 원본 보존, 낮은 양의 용량 보존, 선택적 높은 QD 마스킹, 중복 cycle 처리, 수명 그룹 경계 검증.

## 기본 처리 기준

`QualityConfig()`의 기본값은 공칭 용량 1.1 Ah, EOL 참조 비율 0.8, 높은 QD 검토 비율 1.2, 높은 QD 마스킹 비활성이다.

| 대상 | 처리 | 이유와 한계 |
|---|---|---|
| 원본 열과 행 | 모두 보존 | 삭제·치환 없이 처리 결과를 비교 |
| cycle 비유한값·0 이하·비정수·중복 | 플래그, QD/IR 분석용 값 마스킹 | 원본 번호 보존; 애매한 중복을 임의 선택하지 않음 |
| QD 비유한값·0 이하 | `QD_analysis`에서 NaN | 양의 방전 용량 곡선 탐색용; 기록 원인은 별도 확인 |
| IR 비유한값·0 이하 | `IR_analysis`에서 NaN | 저항 평균 등에 0이 실제 측정값처럼 섞이지 않게 함 |
| QD >1.32 Ah | 플래그만 적용 | 공칭 용량 ×1.2인 휴리스틱; 측정 오류로 확정하지 않음 |
| 높은 QD 선택적 처리 | `mask_high_qd=True`일 때 해당 QD만 NaN | 민감도 탐색용, 기본 결과와 구분 |
| 낮은 양의 QD | 유지 | 실제 열화·수명 종료 구간을 제거하지 않음 |
| 온도·QC·충전 시간의 0값 | 원본 유지 | 모든 변수에 같은 결측 규칙을 일괄 적용하지 않음 |
| 수명 누락·비정상 | 플래그, 셀 유지 | 그래프에서는 회색; 수명 그룹 대표 선정에서는 제외 |
| cycle > 수명 | 플래그, 행 유지 | 수명 기준 도달 뒤에도 측정이 이어질 수 있음 |

NaN으로 가린 지점은 그래프 선이 끊어진다. 행을 삭제해서 떨어진 두 회차를 이어 그리지 않는다. 이 단계의 분석용 열은 후속 Feature 생성의 최종 정제 규칙이 아니다.

### Batch 1

모든 셀의 원본 cycle 1에서 QD·QC·IR·온도·충전 시간 지표가 모두 0이다. 초기화 또는 기록 처리와 관련된 패턴일 가능성이 있지만 원인은 확정하지 않았다.

높은 QD 두 건은 셀 0의 cycle 12에서 1.5390544 Ah, 셀 18의 cycle 40에서 2.8840845 Ah이다. 기본 분석용 곡선에는 유지되므로 상단 조건을 바꿔 영향을 비교할 수 있다.

수명 값은 46개 셀 모두에서 기록 최대 cycle +1이다. 기록된 유효한 양의 QD 중 0.88 Ah 이하 관측은 없다. 따라서 저장 수명을 모두 관측된 EOL 회차라고 표현하지 않는다. 기록 종료 규칙과 셀별 시험 완료·연장 여부를 확인해야 한다.

### Batch 2

수명 값이 있는 39개 셀 모두에서 첫 QD ≤0.88 Ah 관측 cycle이 저장된 수명과 일치한다. 총 970개 행은 그 이후에도 측정이 이어진 기록이다. 단순히 마지막 cycle이 수명과 다르다는 이유로 잘못된 기록이라고 판정하지 않는다.

셀 40–46의 IR은 전체 회차에서 0이다. 총 4,904개 값이 `IR_analysis`에서 NaN이며, 이 셀들에는 유효 IR 관측이 남지 않는다. 이후 IR Feature의 관측 수와 결측 처리 전략이 필요하다.

수명 누락 셀은 22, 23, 35, 36, 37, 38, 39, 40이다. 이 목록과 높은 QD값의 발생 원인은 별도 검토 대상이다.

### Batch 3

수명 값이 있는 44개 셀 모두에서 수명은 기록 최대 cycle +1이다. 유효한 양의 QD 중 0.88 Ah 이하 관측은 없다. 수명 누락 셀은 23, 32이다. 기록이 종료된 방식과 제공된 타깃의 의미를 확인해야 한다.

## 대표 셀 선정과 첫 그래프 관찰

대표 셀은 유효한 수명 값으로 그룹을 나눈 후 그룹 중앙값에 가장 가까운 셀이다. 동률이면 cell_id가 작은 셀을 선택한다. 대표는 그룹 평균이나 전체 그룹의 증거를 대신하지 않는다.

| Batch | 단수명 <500 | 중간 500–1000 | 장수명 >1000 |
|---|---|---|---|
| 1 | 해당 셀 없음 | 셀 11, 수명 788 | 셀 2, 수명 1177 |
| 2 | 셀 11, 수명 449 | 셀 9, 수명 791 | 셀 33, 수명 1140 |
| 3 | 해당 셀 없음 | 셀 5, 수명 828 | 셀 19, 수명 1155 |

Batch 2·3 대표 곡선에서 후기 용량 감소가 초기보다 가파른 구간이 보인다. Batch 2의 선택된 단수명·장수명 대표에는 초기의 일시적인 용량 급락도 보이므로, 원인을 확인하지 않은 채 모두 정상 열화로 해석하지 않는다.

Batch 3의 대표 두 셀은 초기 용량이 비슷하지만 후기 곡선의 진행 속도가 다르다. 이는 초기 전체 용량 외에도 상세 곡선 변화나 기울기를 검토할 동기이며, 아직 Feature의 유효성을 확정한 결과는 아니다.

대표 그래프의 y축은 행별로 공유하고 각 유효 패널에 숫자를 표시한다. 전체 구간은 원본/분석용 값을 겹쳐 표시하고, 초기 확대는 분석용 값만 표시한다. 원본 초기 0값과 스파이크는 별도 전체 개요 및 표에서 확인한다. 초기 구간에서는 작은 변화를 확인하도록 EOL 선을 표시하지 않고, 전체 구간에서만 0.88 Ah 참조선을 표시한다. 전체 셀 개요 그래프의 색 범위는 Batch별 수명 범위이므로 Batch 간 색 자체를 같은 수명으로 비교하지 않는다.

## 외부 근거와 현재 파일의 차이

[원 논문](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)은 공칭 용량 1.1 Ah와 80% 수명 기준을 설명한다. 여기서는 0.88 Ah를 점검 참조로 사용한다.

[원 저자의 LoadData.m](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation/blob/master/LoadData.m)은 첫 Batch의 일부 셀을 두 번째 실험 기록과 연결하고, 기준 용량 도달과 미도달 기록 종료를 구분해 라벨을 계산한다. 해당 코드의 두 번째 파일은 **2017-06-30**이며 현재 프로젝트의 **2018-02-20**과 다르다. 셀 인덱스와 제외·연장 규칙을 그대로 옮기지 않았다.

현재 원본 셀 식별자는 파일 내 위치다. barcode/channel 표현을 근거로 동일 물리 셀임을 확정하지 않았으며, 후속 학습·검증 분리 전에 확인해야 한다.

## 다음 확인할 질문

2. Batch 1·3의 기록 종료 +1 수명 값은 셀별로 어떤 의미인가? 미완료·실험 연장 또는 별도 라벨 산출을 어떻게 구분할 것인가?
3. 현재 세 파일 사이에 동일 물리 셀의 연장 기록이 있는가?
4. cycle 10·100이 상세 `cycles` 저장 위치와 어떻게 대응하는가?
5. 대응을 검증한 후 ΔQ(V)의 장·단수명 차이와 Batch 간 일관성을 확인할 수 있는가?
