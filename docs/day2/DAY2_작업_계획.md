## 3. 학습 전 확인과 학습 테이블

1. 수명 라벨의 정의와 배치 간 기록 연장 여부를 확인한다. 기존 유효 라벨 수 46·39·44는 파일 항목 수이며 독립 물리 셀 수로 확정하지 않는다.
2. barcode·원본 메타데이터·기록 관계로 동일 물리 셀을 점검한다. cell_id 일치만으로 동일 셀을 단정하지 않는다. Batch 1과 Batch 2에 같은 셀이 연결된다면 원자료 처리 근거를 확인하고 분리·통합 방식을 기록한다. 테스트 독립성 확인 전에는 최종 성능으로 확정하지 않는다.
3. Q100/Q10의 실제 회차 대응과 전압 격자를 확인한다. 잘못된 곡선 대응은 단순 결측과 구별한다. Batch 3의 Qdlin 차이는 선택 평가 전에 별도로 점검한다.
4. 제외 기준·적용 단계·사유·항목 수를 기록한다. 테스트 오차가 크다는 이유로 셀을 삭제하지 않는다. 논문의 제외 사례를 적용하려면 해당 셀과 근거를 먼저 확인한다.

학습 테이블은 물리 셀 식별 정보, batch, cell_id, 충전 프로토콜, cycle_life, log10 ΔQ 분산, 마스킹/유지 QD 기울기, 품질 플래그를 포함한다. 식별자와 batch는 관리·분할용이며 기본 모델 입력에서 제외한다. 타깃 누락 항목은 지도학습에서 제외하고 원본은 유지한다. 최종 분할 수는 점검 후 다시 산정한다.

## 4. Batch 1 분할과 누수 방지

공식 요구사항의 `Train (Batch 1 CV)`는 학습 데이터에 대한 재대입 오차가 아니라 CV 검증 fold들의 평균 성능으로 해석한다.

1. Batch 1에서 Hold-out을 먼저 분리하여 보관한다. 초기안은 약 20%이며, 그룹 수·표본 수를 확인한 뒤 정확한 수와 고정 seed를 기록한다.
2. 나머지 Batch 1 개발 집합에서 CV로 특징·타깃 표현·하이퍼파라미터를 선택한다. 같은 fold를 후보 간 공통 사용한다.
3. 선택 설정을 개발 집합 전체에 적합하고 Hold-out MAPE를 평가한다. Hold-out을 반복 튜닝에 사용하지 않는다.
4. 설정을 고정하고 적격 Batch 1 전체로 재학습하여 Batch 2를 평가한다. 최종 재학습에 Hold-out이 포함되며, 표의 Hold-out 성능은 재학습 전 개발 모델에서 산출됐음을 밝힌다.
5. Batch 2 결과를 보고 모델·제외 기준·전처리 설정을 다시 선택하지 않는다. 변경이 필요하면 최종 테스트를 이미 확인한 개발 반복임을 기록한다.

**그룹 처리:** 동일 물리 셀의 기록은 모든 분할에서 같은 그룹에 둔다. Hold-out만으로 같은 충전 프로토콜의 겹침이 방지되지는 않는다. 과제의 프로토콜 겹침 방지 취지를 반영해 동일 충전 프로토콜도 같은 그룹으로 유지하는 Hold-out·CV를 우선 검토한다. 프로토콜은 임의로 합치지 않고 정규화 규칙과 교집합을 기록한다. 그룹 수가 충분하면 최대 5-fold로 시작하되, 실제 수에 따라 축소한다. 그룹 제약으로 평가가 불가능하거나 한 fold가 지나치게 작으면 해당 한계와 조정 이유를 모델 비교 전에 문서화한다.

결측 대체·표준화와 모델을 Pipeline으로 구성하고 각 CV 학습 fold에서만 적합한다. 모델 설정 선택도 개발 집합 내부에서 수행한다. 수명 그룹·knee·전체 기록 길이·수명 이후 정보는 초기 예측 입력에서 제외한다.

## 5. 후보 비교와 선택 순서

| 순서 | 비교 | 확인할 내용 |
|---|---|---|
| 1 | 학습 수명 중앙값 예측 | 특징 없는 공통 기준 성능 |
| 2 | F1/F2 × 일반 선형 회귀/Ridge | 기울기·규제의 추가 효과 |
| 3 | 변환하지 않은 수명/로그 타깃, QD 유지/마스킹 | MAPE와 개별 오차의 민감도 |
| 4 | 선정 특징의 Ridge/제한된 Gradient Boosting | 비선형 모델의 추가 효과 |
| 5 | 필요할 때 ΔQ 최솟값 대체·최대 전류 추가 | 작은 후보 확장의 이득 |

CV 평균 MAPE를 주 기준으로 선택하고 fold별 편차와 단순성을 함께 확인한다. 좁은 성능 차이를 확정적 우위로 표현하지 않는다. 탐색 조합은 사전에 제한해 기록하며, 단계별 선택에도 CV가 반복 사용됐다는 한계를 남긴다. 최초 범위는 Ridge alpha 0.1·1·10·100, 부스팅 깊이 1·2 × 트리 수 50·100, 최소 리프 10·학습률 0.05다. 최적 설정으로 확정한 값은 아니다. 결측 대체가 불가능한 입력이나 로그 적용 불가능한 값은 조용히 보정하지 않고 사유와 처리를 기록한다.

예측은 원래 cycle 단위로 복원한 뒤 평가한다. 로그 역변환이 MAE·MAPE 개선을 보장하지 않으며, 비양수 예측이 생기면 건수와 처리 방침을 명시한다.

## 6. 성능표와 Gap 정의

과제에서 지정한 회귀 목표는 **MAPE 9.1%**다. 논문과 본 과제의 전처리·독립 셀 수·분할·특징이 같다고 가정하지 않으며 목표와의 차이를 논문 재현 성공 여부와 구별한다.

| 구분 | MAPE (%) | 비고 |
|---|---:|---|
| Train (Batch 1 CV) | 미실행 | Hold-out 제외 개발 집합의 검증 fold 평균 |
| Valid (Batch 1 Hold-out) | 미실행 | 선택 설정을 개발 집합에 적합한 모델 |
| Test (Batch 2) | 미실행 | 설정 고정 후 Batch 1 전체로 재학습한 모델 |
| Gap (Train-Valid) | 미실행 | Valid − CV, %p |
| Gap (Valid-Test) | 미실행 | Test − Valid, %p |
| Gap (Target-Test) | 미실행 | Test − 9.1, %p |

과제의 `(+)` 해석에 맞춰 위 뺄셈 방향을 명시한다. 첫 Gap의 양수는 Hold-out 오차 증가, 둘째는 batch 간 성능 저하, 셋째는 목표 초과를 뜻한다. CV·Hold-out의 그룹과 표본 차이, 테스트 모델의 학습량 증가도 Gap에 영향을 주므로 과적합이나 batch 효과로만 단정하지 않는다. CV fold별 표본 수·MAPE·평균·편차와 Hold-out/Test 표본 수를 함께 남긴다. MAE·RMSE는 보조로 저장한다.

요구사항의 `Regression: F1-Score, Accuracy` 문구는 분류 지표가 섞인 표기로 보이며, 선택한 회귀는 명시된 회귀 표와 MAPE 기준을 따른다.

## 9. 학습 전 점검 결과 (2026-10-02)

[데이터 점검 보고서](../../outputs/reports/day2/data_audit_report.md)에 상세 근거와 표를 정리했다.

- MATLAB 문자열 객체에서 실제 barcode를 복원했다. 대소문자 통일 후 세 batch 간 barcode 교집합은 0이며, 객체 핸들 값 자체는 물리 셀 식별자로 사용하지 않는다.
- 과제 Batch 2는 내부 날짜가 2018-02-20이다. 원저자 코드의 Batch 2(2017-06-30)와 다르므로 해당 코드의 병합·제외 인덱스를 그대로 적용하지 않는다. 9.1%와의 비교에는 이 데이터 구성 차이를 명시한다.
- Batch 1의 10개 셀(`0, 1, 2, 3, 4, 8, 10, 12, 13, 22`)은 저장된 라벨 회차 직전에도 QD가 0.90 Ah보다 높다. 해당 원본 관측과 원저자의 중단·연장 처리 근거에 따라 기본 회귀 집합에서 제외하는 36개·20개 프로토콜 구성을 권고한다. 원본과 라벨은 변경하지 않았고, 46개 전체 구성은 별도 민감도 비교로 구분한다. 0.90은 확인용 표시이며 보편적인 자동 제외 기준이 아니다.
- Batch 2 유효 라벨 39개는 최초 QD≤0.88 회차와 일치하며, 이후 기록이 15–66회 존재한다. 유효 39개를 테스트로 유지하고 초기 100회만 입력으로 사용한다.
- 원본 Batch 1 46개 기준 예비 분할은 개발 35개·Hold-out 11개이며, 그룹 5-fold가 가능했다. 권고하는 36개 구성은 동일 seed 42·20% 그룹 Hold-out에서 개발 29개·Hold-out 7개다. 확정 학습 테이블과 분할 목록은 다음 단계에서 저장한다.

다음 작업은 제외 사유를 포함한 초기 특징 학습 테이블과 그룹 분할 목록 확정이다. 기존 46개 기준 예비 분할을 확정 학습 목록으로 사용하지 않는다.

- Batch 1의 10개 불확실 라벨을 기본 구성에서 제외했다. 정답 누락 10개와 함께 전체 표·제외 사유 표에 남겼으며, 원본 라벨은 변경하지 않았다.
- 개발 29개·Hold-out 7개, seed 42·프로토콜 그룹 20% 분할을 고정했다. 개발 5-fold의 학습/검증 수는 23/6 네 회와 24/5 한 회다.
- CV 목록·그룹 교집합·Parquet 값과 자료형을 검증하고 확인 노트북의 새 커널 실행 출력을 저장했다. 모델 적합·결측 대체·표준화는 미실행이다.

현재 다음 작업은 중앙값 기준 모델과 F1/F2 선형 회귀·Ridge의 개발 CV 비교다. 위 9절의 46개 예비 분할과 다음 작업 문구는 점검 당시 기록이며, 실제 학습에는 이번 확정 분할을 사용한다.

## 11. 첫 모델 비교와 설계 변경 (2026-10-02)

[첫 모델 비교 보고서](../../outputs/reports/day2/linear_comparison_report.md)와 [실행 노트북](../../notebooks/07_day2_linear_comparison.ipynb)을 작성했다. 개발 29개·고정 5-fold에서 중앙값, F1/F2 선형 회귀·Ridge, 변환하지 않은 수명/로그 타깃의 21개 구성·105회 학습을 비교했다.

- F1 변환하지 않은 수명 선형 회귀의 평균 fold MAPE는 8.616772%, Ridge α=0.1은 8.612355%다. 작은 차이를 우위로 확정하지 않고, 더 적은 설정의 선형 회귀를 다음 단계 주 후보로 채택한다. Ridge는 비교 후보로 유지한다.
- F2 변환하지 않은 수명 선형 회귀는 평균 11.33%와 큰 fold 편차를 보여 기울기를 기본 입력에서 제외한다. F2의 보조 효과는 이후 대안 비교로 확인할 수 있다.
- 로그 타깃의 평균 오차 이득이 뚜렷하지 않아 변환하지 않은 수명을 우선한다. CV 선택의 한계와 fold 편차를 함께 기록한다.
- 현재 실험은 Hold-out·Batch 2/3를 평가하지 않았으며 최종 모델을 확정하지 않았다. 그래프 3개·셀별 예측·계수·표준화 통계를 저장하고 테스트 2개·새 커널 실행으로 검증했다.

다음 작업은 대표 ΔQ 통계 교체와 기울기 유지/마스킹 대안을 같은 개발 CV에서 비교하는 것이다. 이후 제한된 부스팅과 비교한다. 학습의 목적은 점수 자체가 아니라 설계한 대안을 구현·비교하고 유지·교체 근거를 설명하는 과정이며, 9.1%는 제출 형식상의 비교 목표로 기록한다.

## 12. Feature 대체·masking 비교 완료 (2026-10-02)

[비교 보고서](../../outputs/reports/day2/feature_comparison_report.md)와 [실행 노트북](../../notebooks/08_day2_feature_comparison.ipynb)을 작성했다. 개발 29개·동일 CV에서 분산/최솟값, 기울기 추가와 유지/masking, Linear Regression·Ridge 두 alpha의 18개 구성을 비교했다. Target은 변환하지 않은 전체 수명으로 고정했다.

- Linear Regression 평균 MAPE는 분산 단독 8.62%, 최솟값 단독 8.89%였다. 작은 차이를 보편적 우열로 보지 않되 현재 기준을 교체할 이득이 확인되지 않아 분산을 유지한다.
- 기울기가 바뀐 셀은 18 한 개이며, masking 효과는 대표 통계와 Ridge alpha에 따라 달랐다. 기울기는 기본 입력에 추가하지 않고, masking의 전역 성능 우위도 선언하지 않는다.
- 다음 단계 기준은 **ΔQ 분산 하나 + 변환하지 않은 수명 + Linear Regression**이며 약한 Ridge와 최솟값은 비교 후보로 보존한다.
- 이전 주요 구성 4개의 평균 MAPE를 재현했고, 새 테스트 3개·기존 CV 테스트 2개와 새 커널 노트북 실행으로 검증했다. 그림 3개·회차별 비교 차이·522개 예측·입력 변화·계수를 저장했다.

현재 다음 작업은 동일한 입력·Target·개발 CV에서 제한된 Gradient Boosting과 선형 모델을 비교하는 것이다. 11절의 다음 작업 문구는 당시 진행 기록으로 보존한다. Hold-out·Batch 2 평가는 후보 선택 이후에 수행한다.

## 13. 모델 교체 비교 완료 (2026-10-02)

[비교 보고서](../../outputs/reports/day2/boosting_comparison_report.md)와 [실행 노트북](../../notebooks/09_day2_boosting_comparison.ipynb)을 작성했다. ΔQ 분산 하나·변환하지 않은 전체 수명·동일 개발 CV에서 선형 회귀, Ridge α=0.1, 제한된 Gradient Boosting 네 설정을 비교했다.

- 평균 CV MAPE는 선형 회귀 8.62%, Ridge 8.61%, 가장 낮은 Boosting 9.90%였다. Boosting의 fold 편차도 더 커 선형 회귀를 유지한다.
- Boosting은 15/29개 셀에서 개선됐지만 일부 낮은 수명 셀에서 크게 악화됐다. 평균만으로 모든 셀의 변화를 설명하지 않는다.
- 최소 리프 표본 10개와 학습 23–24개의 제약으로 요청 깊이 2도 실제 깊이 1이었다. 네 Boosting 설정은 실질적으로 두 가지 예측 결과이며, 전체 Boosting 계열의 우열로 일반화하지 않는다.
- 30회 CV와 별도 해석용 개발 적합 3회, 그림 3개·174개 검증 예측·실제 트리 점검 결과를 저장했다. 테스트 7개와 새 커널 노트북으로 검증했다.

다음 작업은 [선택 설정](../../outputs/tables/day2/boosting_comparison/candidate_selection.json)을 고정해 개발 29개로 학습한 뒤 Hold-out 7개를 확인하는 것이다. 점수를 보고 설정을 다시 고르지 않는다. 이후 Batch 1 유효 36개로 재학습하고 Batch 2 최종 평가·Gap·오류 분석을 진행한다. 이전 절의 다음 작업 문구는 당시 기록으로 보존한다.

## 14. Batch 1 Hold-out 평가 완료 (2026-10-02)

## 15. Batch 2 최종 테스트 완료 (2026-10-02)
