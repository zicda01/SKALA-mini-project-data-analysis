# (참고) 산출물 평가 항목

출처: 사용자 제공 평가 기준 이미지.

## 모델 전략 수립

| 평가항목 | 평가 내용 | 배점 |
|---|---|---:|
| EDA | 핵심 변수 분포 탐색<br>통계량 확인 및 해석<br>Feature Selection & Engineering | 50 |
| EDA → 전략 연결성 | EDA 기반으로 시사점 도출<br>연결 논리의 일관성 | 30 |
| 모델링 전략 수립 | Feature 설계 논리<br>모델 선택 논리 | 20 |
| **총점** | | **100** |

## 모델 개발 및 평가

| 평가항목 | 평가 내용 | 배점 |
|---|---|---:|
| 전략 → 구현 반영 | 전략 기반으로 Feature 및 모델 구현 | 20 |
| Pipeline 개발 | 개발 파이프라인<br>데이터 분할 적절성<br>핵심 변수 구현 | 40 |
| 성능 리포팅 및 해석 | 성능 정리 (포맷 기반)<br>목표 성능 대비 Gap 해석력 | 20 |
| 분석 결과 해석 | 분석 결과의 도메인 관점 해석<br>개발 한계점 도출 | 20 |
| **총점** | | **100** |

원본 이미지의 구분별 총점을 각 표의 마지막 행에 표시했다. 평가항목·평가 내용·배점은 원본 표를 옮긴 것이다.
